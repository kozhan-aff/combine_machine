# content_guides — правила письма для генерации текстов (M4)

Сюда кладутся твои рекомендации, как писать тексты: стиль, тон, структура, запреты, примеры.
Комбайн склеивает их в системный промпт писателя и критика.

Как раскладывать:
- `*.md` / `*.txt` в корне — действуют на все страницы всех сайтов;
- `ru/`, `en/`, `es/` … — только для этого языка вывода;
- `review/`, `comparison/`, `howto/` — только для этого типа страницы.

Файлы читаются по алфавиту, поэтому порядок задаётся префиксом: `10-тон.md`, `20-структура.md`.
Бокс: `D:\combine_machine\content_guides\`. Загрузка через панель: карточка «Правила письма» на `/settings`.
Папка в git: правила — часть конфигурации, не секрет. Лимит ~40 000 символов на итоговый промпт,
превышение видно предупреждением на карточке сайта.
