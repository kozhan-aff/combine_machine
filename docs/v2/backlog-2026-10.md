# Бэклог после плана Б и ночи 2026-10-10→11

Собрано из ревью задач, двух финальных ревью ветки и живого прогона. Порядок внутри разделов — по пользе.
«Цена» — моя оценка объёма, не обещание.

## Решения оператора (не код)
- **Порог критика.** С нынешними правилами письма критик за два круга не одобряет ни одной страницы (7–18 обязательных
  замечаний на вычитку, в основном стиль и ИИ-маркеры). Варианты: одобрять самому одним кликом; считать стиль
  пожеланием (блокируют только факты, право, бренд, язык, копирование); дать больше кругов (сейчас 2, круг ≈ 5–6 мин).
- **Ниша.** Свод правил оператора написан под iGaming, сайты — VPN; выжимка переносит предметно-нейтральное.
  Если портфель уходит в гемблинг — завести профиль ниши (настройка «Ниша сайтов» уже есть) и свой датасет фактов.
- Партнёрская ссылка Durev VPN (сейчас голый домен); права токена Cloudflare на чтение статуса SSL.

## Ворота и писатель/критик
- Пауза для сайта, где вычитка падает исключением каждый проход: нужен свой столбец попытки (сейчас строка ошибки
  в каждом проходе, лимит не занимает). Малая.
- Кто одобрил страницу (человек / критик) — не записывается. Малая; полезно для первых боевых прогонов.
- `queue_confirm_action` пишет «Заказ подтверждён», даже когда сервис вернул отказ с пояснением (было и раньше). Малая.
- Перерисовка редактора с текстом оператора, когда страницу переписали, пока он её правил (сейчас отказ со словами
  «верни текст кнопкой назад»). Средняя.
- Язык страницы при смене оффера сайта: наследуется от страниц; брать от оффера — решение оператора. Малая.
- Бренд без датасета фактов: пункт 5 чек-листа делает замечанием любую характеристику — такие сайты критик не одобрит.
  Нужен способ дать факты без правки кода (поле у оффера / экран). Средняя.
- Строка `advice`, добавляемая кодом, когда объём между жёсткой границей и ориентиром. Малая.

## Проверка чисел
- Числа, слитые с буквой (`10Gbps`, `950Мбит/с`, «5к»), не видны ни в досье, ни на странице — править регулярку
  на обеих сторонах сразу. Средняя.
- Закрытые наборы идентификаторов дают ложные замечания на `TCP 443`, `UDP 1194`, `DH 2048`, `802.11ac`,
  «Android 4.4» — расширять по живым страницам. Малая, по мере находок.
- «2 026 серверов» проходит как год; группы, разорванные тегом или апострофом (`7'500`). Малая.

## Код и тесты
- Три копии классификатора «шлюз недоступен / отказ одной страницы» (писатель, критик, выжимка) — один помощник,
  типизированные отказы из `LlmClient`. Средняя.
- Мёртвый код: старый путь генерации без досье (жив ради JSON API и старых тестов), `use_competitor` и
  `competitor.outline_for`, `guides.list_guides`, `page_doc.doc_text`. Убирать вместе с переносом тестов. Средняя.
- Вынести проверки кодом из `content_critic.py` (≈1000 строк) в `critic_checks.py`. Малая, механическая.
- Изоляция `CONTENT_GUIDES_DIR` в общем `conftest.py`, а не пофайловыми фикстурами. Малая.
- Тесты гонок опираются на SQLite: блокировки строк PostgreSQL не доказаны тестами (доказаны условные UPDATE). Средняя.
- Флак под нагрузкой: `test_job_lease.py::test_live_but_silent_job_keeps_its_lock` (тайминг 0,05 с). Малая.

- Таблицы шире карточки на 1024 px («Покупка», журнал автопилота, «Весь список») — прокручиваются внутри. Средняя.
