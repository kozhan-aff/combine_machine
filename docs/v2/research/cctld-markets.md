# ccTLD целевых рынков: может ли иностранец владеть доменом

Сбор: 2026-10-01. Профиль владельца: иностранец не из ЕС, без местного юрлица, оплата криптой.
Правила проверены по сайтам реестров. RDAP сверен по IANA bootstrap (`data.iana.org/rdap/dns.json`,
выпуск 2026-09-30). ✓ — подтверждено, НП — не подтверждено.

Регистраторы: PB = Porkbun, DD = Dynadot, NS = NameSilo, SS = Spaceship, OP = Openprovider.

**Про trustee.** Почти нигде легального trustee нет. В .ca и .com.au за trustee или proxy домен удаляют.
В .nl, .ie и .do регистрация на третье лицо запрещена. Где trustee формально возможен (.it, .no, .bg, .uy),
юридическим владельцем становится он сам. **Под портфель trustee не брать.**

## Светофор

**Зелёные — открыты, владелец сам иностранец:**
- LatAm: .mx/.com.mx, .co/.com.co, .cl, .pe, .ec, .cr, .gt, .do
- Европа: .pl, .cz, .pt, .ro, .gr, .si, .rs, .lt, .lv, .fi, .se, .nl, .be, .ch, .com.hr
- Англоязычные: .co.uk, .co.nz, .co.za
- Азия: .com.tr, .ae (2-й уровень), .id, .my, .in/.co.in, .vn (с проверкой e-ID, пройдёт ли — НП)

**Жёлтые — домен на себя, но с условиями:**
- .com.ar — апостиль и перевод, операции только через NIC
- .sk — почтовый адрес в ЕС/ЕЭЗ
- .hu — обоснование + венгерский регистратор
- .ee — eID или банковский перевод со своего счёта (**криптой не пройти**)
- .dk, .at — проверка документов (для .at с 01.10.2026 по закону NISG)
- .es — «связь с Испанией»
- .ie — только компания с торговлей с Ирландией
- .uy — местный адрес и агент

**Красные — закрыты, вместо них .com на языке страны:**
.com.br, .com.uy, .no, .it, .bg, .hr (2-й уровень), .ca, .com.au, .co.ae, .co.id, .com.my, .co.th

## Риск для VPN-контента

- Отзыв домена по требованию властей или суда прописан в правилах .com.tr, .vn, .in, .ae.
- Прямого запрета на VPN-контент в правилах реестров не найдено.
- **Для VPN-сайтов под Турцию, ОАЭ и Вьетнам надёжнее .com на языке страны, а не их ccTLD.**
- РФ исключена целиком: реклама VPN запрещена с 01.03.2024, штрафы по 281-ФЗ с 01.09.2025 (по СМИ).

## Что подключать первым (под discovery)

- **Сразу, продаёт NameSilo:** .co.uk (Nominet), .mx (registry.mx).
- **После Dynadot:** .pl, .cl, .se (OP), .com.tr (OP), .co.nz через Catched.
- **Без drop list, только EMD и ручные регистрации:** .co, .pe, .ec, .si, .nl, .pt, .ro, .lt, .lv, .be, .ch, .in.
