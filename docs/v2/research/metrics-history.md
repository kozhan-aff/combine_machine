# Метрики и история доменов: источники для скоринга

Сбор: 2026-10-01. **[ДОК]** — официальная дока, **[ЖИВЬЁМ]** — проверено запросом,
**[ВТОР]** — сторонний источник, **[НЕТ]** — не подтверждено.

## Ahrefs API v3: основной инструмент

- **Подписка:**
  - Enterprise 2022: **2 000 000 units в месяц**, сброс 4-го числа;
  - API-ключ есть, истекает в 2036 году.
  - [ЖИВЬЁМ 2026-10-01, `subscription-info`, сам эндпоинт бесплатный]
- **Как считается цена:**
  - стоимость = max(50, стоимость полей × строки);
  - ответ из кэша бесплатный;
  - лимит 60 запросов в минуту, при превышении 429. [ДОК]
- **`public-domain-rating-free`** — до 1000 доменов за запрос, **0 units** [ЖИВЬЁМ дважды].
  У несуществующего домена DR = 0.
  - **Лицензия** (ahrefs.com/legal/domain-rating-license) [ДОК]:
    - рядом с показанным DR обязательна подпись «Domain Rating by Ahrefs» со ссылкой на ahrefs.com;
    - запрещено «scrape, search, crawl, extract or harvest DR Data in bulk or systematically»
      ради конкурирующего датасета;
    - Ahrefs может «restrict, or withdraw DR APIs … at any time and without notice».
  - **Вывод:** внутренний скрининг прямо не запрещён, но 130 тыс. доменов в день — это
    «systematic», и доступ могут отозвать. Как снижаем риск:
    - запрашиваем DR **один раз на домен** (дедупликация);
    - сначала офлайн-префильтр по имени;
    - есть фолбэк, см. ниже.
- **`batch-analysis`** — до 100 доменов за запрос. Отдаёт DR, UR, refdomains и refdomains_dofollow,
  backlinks, refips_subnets, org_traffic, org_keywords. 7 полей ≈ **24 units за домен** [ЖИВЬЁМ];
  набор подпроекта 1 (6 полей + `index` + `url`) — **25 units за строку** [ЖИВЬЁМ 2026-10-01].
  - Строки ответа сопоставлять **только по `index`** (0-based по порядку `targets`): `url` приходит
    со слэшем (`nordvpn.com/`), а IDN — в Юникоде (`пример.рф/`), хотя отправлен punycode [ЖИВЬЁМ].
- **`site-explorer-anchors`** — поля anchor, refdomains, first_seen/last_seen, `is_spam`.
  50 строк = **450 units** [ЖИВЬЁМ].
- **`refdomains-history`** + **`metrics-history`** — помесячно. За 5 лет примерно 360 + 660 units [ЖИВЬЁМ/оценка].
- **Ahrefs через A-Parser с капчей больше не нужен.**

**Фолбэк, если бесплатный DR отзовут:**
- Common Crawl web graph — граф на уровне доменов, бесплатно, раз в квартал. Офлайн-фильтр
  «у домена вообще есть ссылки».
- Или DR-only через `batch-analysis` с жёстким капом.

## Другие ссылочные метрики (не берём на старте)

- **Majestic API** — $399.99/мес, только тариф API. TTF (тематика входящих ссылок) ловит смену темы.
- **DataForSEO** — `bulk_ranks`/`bulk_spam_score`, до 1000 целей за запрос, ~$0.06 на 1000 доменов,
  оплата по факту. Годится как дешёвое второе мнение о спаме.
- **Moz** — бесплатно 50 строк в месяц, Starter $20 [ВТОР, сайт блокирует агента].
- **Semrush, SE Ranking** — дороже, не нужны.

## Возраст и доступность

- **RDAP**, бутстрап IANA `dns.json` (1203 TLD).
  - Есть: .com/.net, .ca, .au, .uk, .online, .xyz, .pl, .nl, .si, .in и др.
  - **Нет:** .nz, .de, .io, .co, .mx, .es, .it и др. Для них whois:43 (A-Parser `Net::Whois`).
  - Лимиты RDAP у Verisign не опубликованы.
- **После дропа RDAP показывает дату НОВОЙ регистрации.** Реальный возраст сайта брать по первому
  снимку Wayback или по `first_seen` в Ahrefs.
- WhoisXML WHOIS History: `preview` за 1 кредит показывает число записей. На старте не берём.

## История и спам

- **Wayback CDX:**
  - `collapse=timestamp:6` — один снимок в месяц;
  - фильтры по `statuscode` и `mimetype`;
  - лимиты не документированы; по [ВТОР] ~60 запросов в минуту, за игнор 429 бан на час с удвоением;
  - держать ~1 запрос в секунду и уважать 429.
- **Анкоры как детектор спама.** Сигналы:
  - флаг `is_spam`;
  - иероглифы, тайский или кириллица на латинском домене;
  - casino/slot/judi/togel/viagra/cialis/replica/loan/porn/essay;
  - волна анкоров по `first_seen` после дропа.
- **Методика SpamZilla** [ДОК, API нет]: возраст, активная история, редиректы, парковки, Domain Drops,
  Language History. Повторяем своими силами: Wayback (3xx/парковки/язык по годам) + Ahrefs.
- **Признаки PBN:** `refips_subnets` намного меньше `refdomains`; всплески в `refdomains-history`;
  большой исходящий профиль.

## Безопасность и блэклисты: условия коммерческого использования

| Сервис | Коммерческое использование | Решение |
|---|---|---|
| Google Safe Browsing | **только некоммерческое**: «for commercial purposes, please refer to Web Risk» [ДОК] | убрать (сейчас ходим через A-Parser — нарушение ToS) |
| **Google Web Risk** | `uris.search` бесплатно до 100 тыс./мес, дальше $0.50 за 1000 [ДОК] | **брать**. Нужен проект GCP с биллингом |
| Spamhaus DBL | публичное зеркало и бесплатный DQS — только некоммерческое [ДОК] | только платный DQS, иначе выключено |
| SURBL / URIBL | бесплатно — с оговорками, для продуктов нельзя [ДОК] | не берём |
| VirusTotal public | «must not be used in commercial products» [ДОК] | **нельзя** |
| OpenPhish Community | коммерция — только Premium [ДОК] | не берём |

## Индекс и санкции

- Google: «`site:` doesn't necessarily return all the URLs that are indexed» [ДОК]. **У дропнутого
  домена пустой `site:` — норма.** Сигнал `indexed_echo` убираем.
- Ручные санкции видит только владелец в GSC, то есть уже после покупки. До покупки надёжного
  сигнала нет: «обвал `org_traffic` при стабильных RD» у expired-домена неотличим от смерти сайта,
  поэтому в воронку M1 (ревизия 2) он не вошёл — оператор смотрит график трафика руками.
- **Политика Google «Expired domain abuse»** (с 05.03.2024). Примеры из неё: affiliate на бывшем
  госсайте, казино на бывшем сайте школы. Значит, **тематическая преемственность — обязательный
  критерий**, а не только чистота истории. При этом прямо разрешено: «It's fine to use an old domain
  name for a new, original site that's designed to serve people first».

## Торговые марки

- **USPTO** — поиска по слову через API нет; только bulk-выгрузка.
- **EUIPO** — Trademark Search API (sandbox, затем заявка на production).
- **IPONZ** — бесплатно для зарегистрированных пользователей.
- **WIPO Global Brand Database** — **автоматизация запрещена**.
- **Практика для нас:** токены имени домена сверяем с локальным списком брендов VPN-ниши
  (nordvpn, expressvpn, surfshark…). Для VPN-портфеля этого достаточно: риск — именно бренды ниши.

## Ручной чек-лист профи и что из него закрывает воронка M1

Воронка закрывает пункты 1, 2, 5 (тема и язык, парковки), 7, 8 и 9 (через тему прошлого сайта). Пункты 3
(история RD — убрана ради units), 4 (обвал трафика — см. выше) и 6 (смены владельца) остаются ручными.

1. DR, RD и их соотношение.
2. Анкоры: брендовые и URL, без иероглифов, фармы, казино.
3. История RD без всплесков и обвалов.
4. Был органический трафик, нет обвала.
5. Wayback: тот же тип сайта, язык и тема; нет парковок, редиректов, «китайского периода».
6. Число дропов и смен владельца.
7. Safe Browsing / Web Risk.
8. Торговая марка.
9. Тема совпадает с оффером.
