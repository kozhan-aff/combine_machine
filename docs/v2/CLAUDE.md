# CLAUDE.md — Комбайн v2 (международный VPN-портфель). Начни отсюда

Этот файл — вход в разработку v2. Корневой `CLAUDE.md` описывает v1 (только .ru/.рф): это история
и уроки, а не текущая задача. Если документы противоречат друг другу, прав `docs/v2/`.

## Что это

Машина полного цикла для портфеля VPN-affiliate сайтов на **международных доменах**. Цикл:
1. найти домен (expired, pending delete, EMD);
2. оценить качество и чистоту истории;
3. купить по API — только после подтверждения человеком;
4. Cloudflare (один из ~10 аккаунтов) + aaPanel на одном VPS;
5. контент на языке рынка через LLM, с обязательной ручной редактурой;
6. публикация и индексация.

**РФ исключена полностью**, вертикаль — **только VPN**.

## Инварианты: в коде, не обходить

Полный текст — `01-master-spec.md` §3. Коротко:
1. **Денежный гейт** — заказ уходит только при `confirmed_by_human=true`. Неизвестный исход →
   `maybe_sent`, отмена блокируется.
2. **Гейт редактуры** — публикуется только `edited`. `draft → edited` делает человек.
3. **Чистая история** — адалт, фарма, казино, гемблинг, спам → жёсткий отказ. Решает детерминированный
   классификатор, не LLM.
4. **Тематическая преемственность** с прошлым сайтом — видна человеку и входит в скор (политика Google
   «expired domain abuse»).
5. **Независимость сайтов** — никакой перелинковки, один Origin-сертификат на домен.
6. **Легальность** — ничего вопреки ToS: ExpiredDomains, SpamZilla, VirusTotal public, бесплатный
   Safe Browsing, WIPO — не автоматизировать.
7. **Не гадать форматы** — живой образец ответа → фикстура → потом парсер.
8. **Герметичные тесты** — `_no_live_network` в `backend/tests/conftest.py` не трогать; платные ключи
   в тестах обнуляет autouse-фикстура `_no_paid_keys`.
9. **Нет авто-одобрения** — скоринг ставит максимум `scored`, `approved` ставит только человек.
   Пакет берёт лишь полностью проверенные домены.

## Как работать

- **Язык — русский везде**: ответы, коммиты, AskUserQuestion, документы.
- **Процесс на подпроект:**
  - спека → план → `superpowers:subagent-driven-development`;
  - на каждую задачу implementer + ревью агентом `combine-reviewer` (`.claude/agents/combine-reviewer.md`);
  - в конце whole-branch ревью.
  - Без одобренных оператором спеки и плана код не пишется.
- **TDD.** Тест сначала. Сьют зелёный и pyflakes чистый после каждой задачи.
- **Коммиты и пуш — только когда оператор попросил.** Работа идёт в ветке, не в `main`. Одобренный
  оператором план разрешает коммит после каждой задачи в рабочую ветку; пуш и мерж — только по слову
  оператора.
- **Доки библиотек — через context7** (FastAPI, SQLAlchemy 2, Pydantic v2, httpx, Alembic, внешние API).
  Не полагаться на память.
- **Отчёт субагента «проверено» — не доказательство**, перепроверять (урок v1: «скриншоты» оказались
  самодельным мокапом).
- **Секреты только в `.env`.** Новые ключи v2: `WEBRISK_API_KEY`, `LLM_CLASSIFY_MODEL`, позже
  `NAMESILO_API_KEY`. `AHREFS_API_KEY` уже есть.
- **Беречь деньги и квоты:**
  - Ahrefs — 2 млн units в месяц, капы в `/settings`;
  - Wayback — ~1 запрос в секунду, уважать 429;
  - CF — не больше 25 зон за 10 минут;
  - aaPanel — 20 неудачных подписей подряд = бан IP на час, ретраи с битой подписью запрещены.
- **`integrations/` — только транспорт, логика в `services/`.** Браузер в рантайме не используем.
